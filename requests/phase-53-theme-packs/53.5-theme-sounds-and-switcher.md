# 53.5 — Per-theme sounds + sidebar quick-switcher

## Why
Sounds are Web-Audio-synthesized (no assets), so theming them is pure
parameters: Console should blip square-wave low, Sprite chime high, Specter
hum spooky. And switching packs shouldn't require a trip to /settings.

## Scope
1. `ThemePack` gains `sound: { freqScale: number; waveform: OscillatorType }`
   (theme-level, not persona). Alert sounds stay untouched — alarms must
   sound like alarms under every theme.
2. `lib/sounds.ts` — `getThemeSoundProfile()` resolves the stored theme to
   its pack profile (default cyberpunk 1.0/sine when unset/SSR);
   `playStartSound`/`playEndSound` scale their frequencies by `freqScale`
   and use the theme waveform.
3. Sidebar footer quick-switcher — compact labeled `<select>` over
   THEME_PACKS calling `applyThemePack`, visible on desktop + mobile drawer.

## Acceptance criteria → tests
- AC1 every pack's sound: freqScale in [0.5, 2], waveform in
  sine|square|triangle|sawtooth → theme-registry.test.ts
- AC2 getThemeSoundProfile: stored "console" → console profile; unset →
  cyberpunk default; garbage → cyberpunk → lib/sounds.theme.test.ts (jsdom)
- AC3 sidebar renders the quick-switcher select with an accessible label
  → sidebar.test.tsx
