# 54.4 — Roadmaps, kanban boards, Linear sync

## Scope
a) Native: Milestone/Board/BoardColumn/Ticket models (org-scoped or
   personal, app-level exactly-one-owner rule, fractional positions).
   `lib/boards.ts` (access checks, positionBetween/positionAfter, board
   creation with default columns Todo/In Progress/Done). Routes:
   /api/boards (list/create), /api/boards/[id] (full board), /api/tickets
   (create/move/edit/delete), /api/milestones (CRUD). UI: /boards page
   with dnd-kit drag between columns; milestones section on /roadmap.
b) Linear: Organization.linearKeyEnc (crypto-box) + /api/orgs/linear
   (PUT key, POST sync) — imports the Linear team's issues into a chosen
   board, linearIssueId keeps sync idempotent (update, not duplicate).
   `lib/linear-sync.ts` with injectable fetch.
