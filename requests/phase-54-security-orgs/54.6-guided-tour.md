# 54.6 — Persona-guided demo tour

## Design call
Hand-rolled spotlight tour instead of NextStepjs: the persona chat-bubble
card IS the product here, our steps span routes (router.push per step),
and a fixed overlay + measured target rect + bubble is ~150 lines with
zero dependency/App-Router integration risk. NextStepjs (research pick)
remains the upgrade path if tours outgrow this.

## Flow (Justin's spec)
Demo session lands with ?demo=1 → **assistant picker first** (theme-pack
grid; choosing calls applyThemePack) → the chosen persona guides the
tour: its portrait + name in a chat bubble anchored to each highlighted
feature, spotlight ring around the target, Next/Back/End controls,
steps route across pages (fleet dashboard → Overseer → Team feed →
Boards → Roadmap milestones → Theme packs). Progress in sessionStorage
so route changes don't lose the tour. If the user enabled voice, the
persona speaks each line (speak() lib, opt-in as ever).

## AC → tests
- AC1 lib/tour-steps.ts: ≥6 steps, unique ids, every route is a real
  app page, selector + title + text nonempty → lib/tour-steps.test.ts
- AC2 anchor drift-guard: each step's selector id appears in the source
  file the step names → lib/tour-steps.test.ts (reads source)
- AC3 tour component: thin, renders from tested steps (tsc/lint; UI
  escape hatch — exists before request complete per tests.md).
